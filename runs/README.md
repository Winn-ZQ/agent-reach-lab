# 本地试跑记录

这些文件用于本机验收，网页原文不默认发布到 GitHub。

| 目录或文件 | 用途 |
| --- | --- |
| setup/search.txt | 第一次真实 Exa 搜索结果 |
| setup/kone.json | 通过 Agent-Reach/Jina 取得的网页全文与采集元数据 |
| setup/analysis.md | 原始主助手报告，保留当时状态文字，不覆盖 |
| kone-review/ | 真实原报告的版本、独立复核与状态记录；复核无需修正即通过 |
| fixture-loop/ | 明确标识的人工错误样本与循环记录，不计作真实准确率 |

查看每次运行的 `state.json` 获取最终状态。`draft-N.md` 为第 N 次修正后的稿件，`review-N.json` 为该稿的复核，`evidence-N.json` 是该轮依据。历史文件保留原貌，旧稿里的“尚未复核”描述代表当时情况。

首次正式复核检查了 7 项核心结论，只证明它们受到所存原文支持。人工测试加入三个全称断言/日期错误，用于检查反馈修正分支。两类样本都很少，不能据此宣称准确率提升或优于通用助手。
