# 通力中国预测性维保：初稿

问题：通力预测性维保服务在中国提供哪些功能？是否所有型号都适用？

证据范围：本轮仅读取通力中国官网云管家产品页 S1；搜索另外发现 service-descriptions 与 how-we-serve-you 两个中国维保页面，尚未读取全文。

## 已有依据的功能

通力中国官网介绍了面向电梯和自动扶梯的云管家服务。以下为厂商功能描述，不是本项目验证的性能：

- S1 正文第 282–284 行：设备监控装置采集参数、使用与故障信息，传至云平台分析。
- S1 第 268–274 行：持续监控，并在检测到严重故障时提醒技术人员和客户。
- S1 第 290 行：依据问题严重程度通知技术人员或联系技术支持、客户服务部门。
- S1 第 294–296 行：向客户报告采取的措施，支持后续维保规划。
