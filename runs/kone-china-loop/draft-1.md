# 通力中国预测性维保：补查后的报告

问题：通力预测性维保服务在中国提供哪些功能？是否所有型号都适用？

## 结论

通力中国官网展示“电梯云管家”，用于电梯和自动扶梯的智能远程监控维保。已读资料支持下列厂商功能描述；本项目没有实测设备效果。

| 功能 | 官网描述的含义 | 已保存证据位置 |
| --- | --- | --- |
| 提前识别潜在问题 | 厂商称可在故障前预测潜在问题，发现维保需求并采取措施；不能理解为可预测全部故障 | S1 第260、266、288–290行 |
| 参数采集和云端分析 | 收集参数、使用和故障信息，实时传到云平台进行分析 | S1 第282–284行 |
| 全天候监控与告警 | 监控运行情况，检测到严重故障时通知技术人员和客户 | S1 第268–274行 |
| 分级响应 | 根据问题严重程度联络技术人员、技术支持或客服；云管家的行动遵循双方商定的服务及响应时间 | S1 第290行；S2 第296–298行 |
| 处理报告与规划 | 向客户报告采取的措施，帮助安排后续维保和预算 | S1 第294–296行 |

## 所有型号都适用吗？

**本次资料不足以确认所有型号均可接入云管家。也不能据此断言某个型号不支持。**

补查发现，服务详情与维保服务页面的确介绍了多品牌、不同类型设备的定制维保能力（S2 第260–262行；S3 第280–286、355–365行）。但是这些段落介绍的是一般维保/预防性维保。S2 另列云管家服务（第296–298行），该段没有给出全品牌全型号兼容承诺。

因此不能把“一般维保覆盖多品牌”转换成“云管家对所有型号通用”。本次读取的三份页面没有提供可用于逐型号判断的云管家兼容清单、接入接口要求或安装条件；S3 的制动器维护附件属于其他主题，本次未读取，不作为云管家兼容证据。

若要判断实际设备能否开通，下一步应由设备方提供品牌型号、控制系统及现有维保信息，向服务方确认接入条件、现场评估及合同范围。这是后续核实建议，不是已确认的官网强制申请材料。本次未代用户联系服务方。
