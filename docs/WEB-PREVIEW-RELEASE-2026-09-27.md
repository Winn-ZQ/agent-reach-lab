# 网页研究预览版收尾单

本轮根据用户确认继续推进，保留既有工作，不改变通用多平台方向。只交付公开网页预览版；小红书下一阶段接入，其余能力逐项验证。语义质量认证与预览版交付分开，历史失败不改判。

## 固定范围

1. 保留方案A、来源中心、旧版工作台、历史任务、模拟回放、取消、暂停、恢复、关联任务、引用与导出。
2. 新任务默认采用已测试的Qwen3.8-Flash分析/修正、Flash思考复核，SSE与compact-v2契约；按任务保存策略。旧任务及旧任务的恢复沿用原策略，不迁移或重放。保留显式旧配置启动方式。
3. 页面及导出以“本轮模型复核未发现问题”表达模型检查结果；不等同事实认证。失败和修改意见仍明确显示，代码中的历史状态不重写。
4. 不增加数字置信度、风险评分、平台专属Agent、自动Max升级或新的澄清系统。
5. 一轮网页验收后整理既有GitHub仓库更新，不再增加困难样例调优轮次。

## 发布硬门槛

密钥不进入前端或公开文件；预算/免费保护继续生效；未接入渠道不显示可用；引用须绑定实际证据；失败/回放不能冒充真实成功；历史版本不得混用；页面及导出一致。任何失败阻断发布，修复后只重测相关分支。

语义评测旧例继续保留失败结论，不能把预览版发布称作稳定质量通过。宣传仅承诺资料获取、证据展示、模型辅助整理与复核，不宣称准确率、复核净收益或无人核对即可使用。重要结论需用户核对。

## 本轮一次验收

- 新默认的模拟集成：正常两步、限制说明修正再复核、预算不足保留来源并继续、未接入必需来源、旧任务兼容与版本策略。
- 正式网页实际提交一个新任务，真实搜索→取得正文→分析→复核→最多一次内容修正→结果/来源/导出。新任务上限5次，失败保留，不以模型pass强行认定语义正确。引用与传输问题如实记录。
- 浏览器检查：输入、来源选择、历史、结果、原文展开、运行设置及导出；来源不足和预算停止采用明确标识的模拟测试，不为制造故障消耗真实额度。
- 主目录与无私有资料副本运行必要测试；核对原历史文件哈希，扫描公开候选，再提交和推送已有仓库。

本轮仍使用既有免费额度观察和累计账本。按证据体积确定任务输入容量并保留后续复核容量；不能通过改任务目录或策略重置旧消耗。若平台额度或登录成为真实阻碍，保留已完成工作并说明。

## 结果

### 实施与兼容

- 新任务默认已接入Flash非思考分析/修正＋Flash思考复核、SSE、compact-v2；策略随任务保存。旧任务及旧版本继续原策略，不自动重跑。
- 报告、导出和运行设置已同步；保留方案A及旧版工作台。PRD v0.3、README、启动/演示和模型说明已更新。
- 比对实施前13个历史任务的26份任务/结果文件，SHA-256全部一致。此次新增任务另存，不改变原失败结论或消费账本。

### 一次真实网页执行

正式页面提交：“请仅依据 Zotero 官方文档，说明免费数据同步与免费附件存储各有什么限制，以及 WebDAV 能否用于群组库。”取得3份正文，回答依据选用官方来源，另2份非官方来源明确排除。搜索/读取、分析、思考复核、修正均实际运行。

最终为 `stopped / segment_ref_schema`，共3次模型请求、修订版本0。修正模型混用了旧引用对象和裸片段字符串，严格校验拒绝该补丁；原稿、证据和复核意见保留，未得到本题通过稿。原稿“超出免费空间需购买”比来源“可购买更大套餐”更强；复核虽要求收窄，但其理由也引入了材料未说明的实际超额行为，不能将此结果视作语义质量通过。

随后补充格式处理：这类补丁结构错误共享已有的一次格式修复机会，并为最终复核留名额，仍受5次总上限约束。模拟测试证明一次修复后可继续复核、再次失败会停止。**此改动没有重跑真实题验证，不能声称已解决真实模型输出问题。**

实际用量：输入25,062、输出2,366（包含复核思考）、合计27,428 Token；从创建到停止约60秒。按此前已核实并记录的Flash单价（输入0.8元/百万、输出2.7元/百万）估算0.0264378元。这里只是本次停止任务的模型标价估算，不是成功报告平均成本，不是实际扣款；采集费用及开发助手成本未计入。没有新增Max调用或付费授权。
