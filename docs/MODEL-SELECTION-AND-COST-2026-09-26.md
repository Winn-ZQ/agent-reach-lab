# 多渠道研究的模型分工与成本核算

核算日期：2026-09-26。本文是选型建议和成本估算，不代表已切换模型、开通付费或完成新模型测试。

> 后续决策更新：用户确认优先验证Qwen3.8-Flash思考复核，Max为对照与增强候选而非默认刚需。对应实现与实际结果见[思考复核对照](THINKING-REVIEW-2026-09-26.md)。下文原始账本统计截至此次对照启动前，不包含本轮新增调用。

补充同样4个样本的Flash方案：分析/修正沿用非思考Qwen Flash，将5次复核也按Qwen Flash价格计算，原Token不变平均0.038428225元/次任务；每次复核额外4K～8K计费输出时，均价为0.051928225～0.065428225元。仍是反事实估算、非合格交付均价，不等于新配置实测；分析/修正开启思考还会增加用量。

## 推荐分工

- Qwen3.8-Flash：简单意图识别、资料提取、分类、初稿；工具选择能力仍需专项验证。
- DeepSeek-V4.1-Flash：先验证开启思考后的复核效果，合格后才能作为低成本常规复核。
- Qwen3.8-Max：优先对比的增强候选，用于复杂研究计划、跨来源矛盾、关键条件复核与复杂修正。效果尚未实测。
- 不按平台各配一套大模型。系统根据渠道能力与授权状态提供可调用工具；模型给出结构化计划，程序校验并执行，输出统一证据结构。
- 图片和视频按需处理。优先使用能取得的正文、字幕；确有画面信息需求时再评测多模态流程。当前文本测试不能证明这些能力已跑通。
- 独立复核必须能回查原文及上下文，不只检查前一模型的摘要；来源链接、条件和原文片段应随证据保留。

## 核算口径

一次问题指用户提交的一项研究任务，可能含多项子问题和多次模型请求。

本次只读取 `.local/research-budgets/live_api-*/events.jsonl` 原始研究流程账本，没有读取密钥，没有新增模型调用。统计不是供应商账单，也不是全项目所有 API 支出：早期连通测试、独立 model-trial、开发助手消耗和外部渠道费用不在内。

公式：费用 = 输入 Token × 输入单价 / 1,000,000 + 输出 Token × 输出单价 / 1,000,000。

使用华北2（北京）官方标价。为便于比较统一不扣免费额度、不计缓存折扣或活动优惠；DeepSeek 分别按全部闲时、全部忙时计算。区间反映价格场景，不是统计置信区间或实际账单上下限。

| 模型 | 输入元/百万 Token | 输出元/百万 Token |
| --- | ---: | ---: |
| Qwen3.8-Flash | 0.8 | 2.7 |
| DeepSeek-V4.1-Flash 闲时 | 1 | 4 |
| DeepSeek-V4.1-Flash 忙时 | 2 | 8 |
| Qwen3.8-Max | 12 | 36 |

来源：[Qwen Flash](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)、[DeepSeek Flash](https://help.aliyun.com/zh/model-studio/deepseek-v4-1-flash)、[Qwen Max](https://help.aliyun.com/zh/model-studio/qwen3-8-max)。思考产生的可计费输出也需要计入。

## 更换模型的反事实估算

固定上述4个样本原有输入、回答输出与调用次数；替换单价后再给每次相应调用增加4,000或8,000个计费输出 Token，作为思考开销的情景假设。不是新模型实测；不同分词、回答长度、是否减少修正或增加查询均未建模。4,000～8,000也不是思考开销的保证范围。

| 配置 | 固定原 Token 的平均费用/元 | 增加假设思考量后的平均费用/元 |
| --- | ---: | ---: |
| 现组合；DeepSeek 复核开启思考 | 0.0664（忙时） | 0.1064～0.1464（每次复核额外4K～8K） |
| 保留 Qwen Flash；复核换 Qwen Max | 0.2789 | 0.4589～0.6389（每次复核额外4K～8K） |
| 分析、修正、复核全部 Qwen Max | 0.5646 | 0.9606～1.3566（每次调用额外4K～8K） |

上述样本平均1.25次复核、2.75次总调用。每次额外4K输出的Max开销0.144元，因此混合方案平均增加0.18元，全Max平均增加0.396元。

### 便于理解的单题例子

假设分析输入20K/输出2K，复核输入22K/输出2K，且一次完成，无修正：

- Qwen Flash + DeepSeek Flash（忙时）：0.0814元。
- Qwen Flash + Qwen Max：0.3574元。
- Qwen Flash + Qwen Max，复核另外产生4K计费思考输出：0.5014元。

这只是两个模型步骤，尚不含未来模型规划、工具反馈循环、更多来源、视觉输入、转写、外部付费服务等费用。

## 多渠道扩展的成本原则

平台数本身不直接产生模型Token费用；实际读取的文本/图像/视频量、计划与工具循环、重复输入以及修正次数会影响费用。

程序优先承担去重、格式检查、数量统计、抓取错误识别等确定性工作。用低成本模型做逐条结构化提取；强模型读取相关证据和必要上下文，进行跨源分析及关键复核。不能为省Token只传摘要而丢失例外条件。

建议后续产品提供普通与增强研究档位，记录模型费、渠道费和未知费用，追加检索前为分析及复核预留预算；开发阶段上限不直接成为产品套餐。当前不据本次估算修改任何运行预算。

原计划的固定证据对照现已完成，结果见下文；尚未执行新配置的完整修正链或独立新题验证。
