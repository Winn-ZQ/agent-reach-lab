# 首版 MVP 冻结单

日期：2026-09-23

这份冻结单用于防止首版范围继续扩大。首版只验证一条完整链路，不代表最终产品能力边界。

## 首版唯一场景

用户输入一个电梯行业公开研究问题，例如：

> 电梯行业预测性维保有哪些公开资料？

用户可以填写地区和时间范围。首版只使用公开网页；小红书、供应商背调、招标、补贴和专利情报暂不加入验收范围。

## 首版流程

1. **输入与计划**：程序校验问题、地区、时间和来源，显示每一步负责人。
2. **获取**：Exa 返回最多 3 个候选，Agent-Reach/Jina 逐页读取；失败页面不能进入分析。
3. **证据准备**：程序给来源分配 S1、S2、S3，校验 URL、采集时间和正文 SHA-256，标记发布日期、地区和范围限制。
4. **分析**：Qwen3.8-Flash 输出 Q1/Q2 的结构化回答、连续引用、限制和假设。
5. **复核**：DeepSeek-V4.1-Flash 检查每个问题和假设；结果只能是 `pass` 或 `revise`。
6. **修正**：只有 `revise` 才允许一次 Qwen 修正，程序重新校验后再次复核。
7. **交付**：生成带状态的 Markdown 和 CSV；未复核结果不能标记为通过。

## 首版完成条件

- 至少 1 个真实公开网页问题能够完成获取、证据准备、分析、复核和交付。
- 每个最终结论都能回指 S 编号和连续原文片段。
- 日期、地区、来源自述和未知项不被模型或程序混成已证实事实。
- 分析失败、复核失败、预算不足和修正上限都能停止并保留记录。
- 模型调用总量、免费/付费状态和失败用量都有记录。
- 没有模型预算时，页面只能预览和预检，不能伪造实时结果。

## 明确排除项

- 小红书登录和用户反馈分析。
- 多平台并行检索。
- 自动登录、读取 Cookie、绕过验证或付费墙。
- 完整移动端适配；主界面布局与操作调整已于2026-09-26移出排除范围，按顶部修订执行。
- 把一次电梯案例包装成通用准确率结论。
