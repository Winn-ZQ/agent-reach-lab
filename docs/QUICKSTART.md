# 从项目副本启动

当前支持 macOS／Linux（任务锁使用 POSIX `fcntl`）；Windows 原生环境未支持，可使用 WSL。需要 Python 3.10+、Git；真实网页搜索另外需要 Node.js 与 npm 或 pnpm。没有密钥也能查看界面和运行离线测试。

## 1. 安装与离线检查

在仓库根目录运行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest -q
.venv/bin/python research_web.py --port 0
```

打开终端打印的本机入口。这是网页研究预览版，尚未通过稳定语义质量认证。默认是方案 A：左侧历史，中间需求与进度，右侧报告与资料。通过侧栏“旧版工作台”进入 `/legacy`，可运行明确标为模拟的四个回放。启动服务和运行测试本身不调用模型；不要把回放结果视为模型实测。

`requirements.txt` 固定 Agent-Reach 源码提交，并通过 `constraints-tested.txt` 固定这次验证过的20项运行依赖版本。这是版本约束，未包含制品哈希；已在 macOS arm64／Python 3.12.14 的全新虚拟环境验证，其他系统仍需验证。

## 2. 接通公开网页获取

```sh
npm install --prefix .tools mcporter@0.13.13
node --version
.venv/bin/python -c "from research_acquisition import node_path; print(node_path())"
```

也可以使用 pnpm 安装（本机已验证；npm 命令本轮未实际执行）：

```sh
mkdir -p .tools
pnpm --dir .tools add mcporter@0.13.13 --save-exact --ignore-scripts
```

最后的 Python 检查应显示存在的 Node 路径。程序优先使用 `AGENT_REACH_NODE`，其次使用 PATH，最后兼容当前用户目录下的 Codex 运行时。自定义安装可以显式设置：

```sh
export AGENT_REACH_NODE="/你的实际路径/node"
export AGENT_REACH_MCPORTER="/你的实际路径/mcporter"
```

通常无需设置这两项。`config/mcporter.json` 仅指向 Exa MCP，不导入编辑器账户配置。搜索及 Jina 读取需要网络和服务可用；依赖安装成功不保证来源可访问，也不代表其他平台已授权。不会自动登录、读取 Cookie 或安装所有平台组件。

## 3. 配置模型（可选；仅真实分析需要）

```sh
.venv/bin/python configure_model_web.py
```

在它打印的本机页面填写自己的百炼 API Key，勿粘贴到聊天或提交到 GitHub。新网页任务默认使用百炼北京 Qwen3.8-Flash：分析/修正为非思考，独立复核为思考模式。旧任务恢复保留原 Qwen／DeepSeek 配置；模型与免费额度是否对新账号可用，需要自行核实。聊天会员不是 API 授权。

已有配置请勿反复创建。密钥保存在本机忽略提交的 `.local/`，不会发送给前端；配置与登录数据不随仓库复制。真实调用前需在模型控制台确认免费额度和“用完即停”，再到工作台“运行设置”记录观察值。额度记录有效24小时，程序不会自动查询平台余额或充值。

## 4. 运行一个任务

当前使用**开发验收配置**，限制适用于本机网页的真实运行，不代表正式产品的固定套餐。目前不支持档位切换或按金额设置日预算；快速／标准研究与费用上限见 [PRD 后续规划](PRD-v0.3.md)。

输入研究问题，选择“公开网页”和所需地区／时间，点击一次“开始研究”。搜索→读取→证据校验→分析→独立复核按条件自动推进，无需逐阶段继续。

每任务最多3页、一次内容修正；新研究最多5次模型请求，已有复核的修正/连接恢复为2次，复核传输失败后的重新复核最多3次。当前验收阶段每天（按任务发起日UTC归属）基础12次，按任务需要自动以4次为步长增加，当前开发阶段最高80次，失败也记账；在途或用量未知保持预留，任务结束且用量已知后释放未用名额。按任务类型预留完整步骤，剩余名额不足时停止派发；不将项目日限额误称为供应商免费额度用尽。额度缺失或不足时保留来源并暂停。报告可能显示“本轮模型复核未发现问题”、要求修正或停止；模型判断仍可能有误，重要结论请对照原文核实。没有有效稿时只交付来源与停止原因，不填演示答案。

终端服务需保持运行，按 Ctrl+C 停止。服务重启会更换本机会话入口，请使用新打印的地址；历史记录保留，运行中断的任务不自动重放。

## 保留旧配置与历史任务

新任务绑定`preview-v1`策略，使用compact-v2引用及复核契约。旧任务没有策略字段时按legacy恢复，不重新搜索或迁移历史结果。需要为新任务使用旧配置时，启动`.venv/bin/python research_web.py --model-policy legacy --port 0`。这不是免费额度重置；两种配置共用历史预算账本。
