# 本阶段最终交付：公开网页研究原型

日期：2026-09-26。范围：质量整改与独立新题、连接失败处理验收、既有GitHub作品更新。全平台接入与新功能扩展不计入本阶段。

**结论：课程原型的实现、验证和发布整理已完成；多题研究质量验收尚未通过，不能称为可靠自动研究产品。** 程序测试通过不等于模型回答正确；历史通力通过例、模拟夹具和本轮失败任务分别记录。

## 已交付

- 本机网页方案A：任务输入、自动进度、历史记录、来源中心、报告/证据/复核以及Markdown与CSV导出。仅公开网页实际可执行，15项目录不是15项已接入能力。
- Agent-Reach/Exa获取 → 保存并校验原文 → Qwen分析 → DeepSeek独立复核 → 最多一次内容修正 → 再复核。证据与草稿版本绑定，预算不足、来源不足或校验失败明确停止。
- 逐问题补丁与修正回执：程序要求修改具体问题目标，独立复核核对修正是否落实；保留修正前后与原始失败。
- 新复核目标清单由程序生成。目标覆盖、来源覆盖或判定与问题列表出现可识别结构矛盾时，整个任务最多追加一次格式纠正，计入原调用上限。伪造引文与网络失败不触发这类纠正；程序不擅自改成通过。
- 空正文包装、带正常导航的缺页外壳不再被当作有效证据；新增测试并对保存的失败页面离线重新验证。

## 连接失败验收

真实本地HTTP测试覆盖响应头前断开、缺少结束标记的SSE、完整SSE返回；每种情况只发送一次请求。失败不冒充成功，保留已知/未知用量，不自动更换模型或重发。既有测试验证固定证据恢复、版本绑定与重复恢复拒绝。

正式网页仍使用JSON接收；SSE为显式开发实验模式。本轮外部服务仍发生一次远端关闭，**已验证故障处理，不代表外部连接稳定性已解决**。
