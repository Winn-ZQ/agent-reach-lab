# 两套主界面交互草稿

日期：2026-09-26。用户已认可 A 与来源中心布局，正式规则见 [PRD v0.3](../../docs/PRD-v0.3.md)；B 保留用于比较。独立静态前端，没有模型、搜索或后端 API 请求，不读取现有工作台数据或凭据。与 web/ 正式原型隔离。

- A：对话与报告并排，适合持续补充研究需求。
- B：输入、执行、报告分阶段，适合一次性交付。
- 相同的 App A/B 虚构证据、报告、复核与下载内容，避免把内容差异当成布局优劣。
- A 自动计时演示进度，B 由“下一阶段”手动推进；两者都不是后台事件。补充需求仅确认交互，不产生新报告。
- 支持来源抽屉、三个结果标签、样例 Markdown/CSV 下载、返回输入、取消、历史任务入口。
- 设置按钮展示说明，未实现真实配置功能。

可直接打开 index.html，或在本目录用 Python 静态服务预览（仅绑定 127.0.0.1）。
